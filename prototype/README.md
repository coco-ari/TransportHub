# Early UI prototype

This directory contains the early browser-based interaction prototype. The
shipping Windows UI lives under `apps/TransportHub.Desktop` and may differ from
these mockups.

Open `transporthub-widget.html` directly in a browser for manual inspection.
To regenerate the screenshots, install Playwright in a temporary Node.js
environment and run:

```powershell
node .\prototype\render-prototype.js
```

The render script uses the locally installed Microsoft Edge browser. Generated
prototype screenshots contain demonstration data only.
